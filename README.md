# 🇵🇰 Pakistan Administrative Units Opinion Poll

A modern, responsive, and lightweight web application designed to conduct a public opinion poll regarding the creation of new administrative units (provinces) in Pakistan. Built entirely with pure HTML, CSS, and Vanilla JavaScript.

## 🌟 Key Features

* **Live Countdown Timer:** Displays real-time countdown targeting the vote closing date (20 Nov 2026).
* **Ethnicity & Language Breakdown:** Allows voters to record their vote based on their linguistic and regional identity.
* **Local Data Persistence:** Uses browser `localStorage` to save poll responses across page refreshes.
* **Interactive Visuals:** Dynamic progress bars reflecting real-time voting ratios (Yes vs. No).
* **Admin Dashboard:** Password-protected panel (`admin123`) displaying aggregated total vote counts and overall percentages.
* **Informative Sections:** Features historical context, economic stats, a proposed administrative map, and reform benefits.

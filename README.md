# 🇵🇰 Pakistan Administrative Units Opinion Poll

A responsive opinion-poll demo about proposed administrative units in Pakistan, built with HTML, CSS, and vanilla JavaScript.

## Features

- Countdown timer targeting 20 November 2026
- Yes/no poll interaction
- Opinion breakdown by selected group
- Dynamic progress bars and summary statistics
- Admin summary panel for demonstration
- Informational sections and proposed map

## Technology

- HTML5
- CSS3 (responsive layout, CSS variables, Flexbox and Grid)
- Vanilla JavaScript (ES6+)
- Browser `localStorage` where used by the project

## Run locally

1. Clone the repository: https://github.com/Hafiz-arman-sheikh/-PakUnits-Poll
2. Open `index.html` in your browser, or use a simple local development server.

## Important limitations

This is a learning/demo project, not a secure or official voting system. Browser-side data is not a shared, authoritative database; visitors may see different results on different devices, and client-side code can be inspected or changed.

The admin panel uses a password check in browser JavaScript. That is not secure authentication and must not protect private data or real voting results. For production, move authentication and vote storage to a backend, add server-enforced authorization, and validate votes on the server.
